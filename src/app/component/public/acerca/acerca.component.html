Te damos la bienvenida a CineSepabase - nuestro sistema integral de gestión cinematográfica.

¿Qué es CineSepabase?

CineSepabase es una aplicación web moderna desarrollada con Angular y Supabase que funciona como un sistema completo de gestión para cines. Está diseñada para ofrecer una experiencia digital completa tanto para los administradores del cine como para los usuarios que desean disfrutar de películas.

¿Qué hace exactamente?

📱 Para Usuarios

  • ✓ Ver cartelera de películas disponibles
  • ✓ Consultar detalles de cada película
  • ✓ Explorar opciones de comida y bebidas
  • ✓ Sistema de autenticación seguro
  • ✓ Interfaz responsive para móvil y desktop

⚙️ Para Administradores

  • ✓ Gestión completa de películas
  • ✓ Control de acceso por roles
  • ✓ Panel administrativo privado
  • ✓ Base de datos en tiempo real
  • ✓ Reportes y análisis

🛠️ Tecnologías Utilizadas

Frontend

Angular 19, TypeScript, Tailwind CSS

Backend

Supabase, PostgreSQL

Herramientas

Angular CLI, NPM, Git
